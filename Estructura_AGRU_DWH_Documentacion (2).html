Contexto del proyecto

Origen del modelo, alcance funcional y parámetros operativos confirmados.

Origen

Informe Power BI Estructura_AGRU_PRUEBA_v3 conectado a un Data Warehouse en SQL Server alimentado desde SAP Business One.

  • Modelo semántico Power BI Desktop (compatibilidad 1600).
  • Scripts ETL: SAP_STGA1F.sql, table_list_24_04_26.sql.
  • Instrucciones de mantenimiento: INSTRUCCIONES_TABLELIST_UPDATE_INSERT.txt.

Parámetros operativos

  • Frecuencia: ciclo completo diario (SAP → stage → DWH → refresh PBI).
  • Herramienta ETL: SQL Server (tablas + procedimientos almacenados). No se usa SSIS/ADF.
  • Multi-empresa: stage particionado por CodEmpresa en bases SAP_STGA*F.
  • Metadatos: catálogo central en AETL_SBOBI_v2.stage.TableList.
Alcance funcional
Cashflow y rendimiento comercial: pipeline acumulativo Pedido → Entrega → Factura → Cobro, trazabilidad línea-a-línea, rentabilidad (coste/margen), OTIF, DSO, acuerdos globales y cobertura de stock.

Modelo de datos

Enfoque dimensional Kimball con hechos transaccionales por línea de documento y un hecho Accumulating Snapshot a nivel de pedido.

Hechos transaccionales

Una fila por línea de documento SAP. Trazabilidad mediante claves compuestas Pedido_Line_Key, Albaran_Line_Key y campos DocOrigen_* / BaseEntry.

Accumulating Snapshot

Una fila por pedido (cabecera) con todos los hitos del ciclo de vida: pedido, entrega, factura y cobro. Soporta KPIs de pipeline, lead times y DSO.

Hecho clave para el análisis cashflow. Una fila por pedido con todos los hitos y duraciones del ciclo.

Importes y volumen

  • Importe_Pedido, Importe_Facturado, Importe_Cobrado
  • Num_Entregas, Num_Facturas
  • Etapa_Actual: 1-Pedido → 2-Entregado → 3-Facturado → 4-Cobrado

Lead times y hitos

  • Dias_Pedido_a_Entrega, Dias_Entrega_a_Factura
  • Dias_Factura_a_Cobro (DSO), Dias_Ciclo_Acumulado
  • Dias_Retraso_Entrega vs fecha solicitada
  • Flags binarios: Flag_Entregado, Flag_Facturado, Flag_Cobrado

Claves de unión y trazabilidad ▶
  • Cliente / vendedor / producto: códigos SAP CardCode, SlpCode, ItemCode.
  • Sucursal: Id_Sucursal ← BPLId en cabeceras de documento.

VAR impF = MAX('Fact_AccumSnapshot_Pedidos'[Importe_Facturado])
VAR impP = MAX('Fact_AccumSnapshot_Pedidos'[Importe_Pedido])
RETURN
  SWITCH(TRUE(),
    ISBLANK(impP) || impP = 0, BLANK(),
    ISBLANK(impF) || impF <= 0, "Sin facturar",
    impF >= impP - 0.01, "Facturado",
    "Facturación parcial"
  )
